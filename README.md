# Portfolio de Daniel Montero Ruiz

## Descripción

Este es el sitio web de portafolio personal de Daniel Montero Ruiz, un desarrollador junior especializado en aplicaciones, apps web, móviles y videojuegos. El sitio presenta una interfaz moderna con efectos de partículas y una experiencia de terminal simulada.

## Características

- **Página de Inicio**: Presentación personal con animación de escritura.
- **Trayectoria**: Información sobre la experiencia profesional.
- **Proyectos**: Muestra de proyectos realizados.
- **Contacto**: Información de contacto.
- **Loader**: Pantalla de carga con terminal simulada.
- **Efectos Visuales**: Fondo de partículas usando particles.js.

## Tecnologías Utilizadas

- **HTML5**: Estructura del sitio.
- **CSS3**: Estilos y diseño responsivo.
- **JavaScript**: Interactividad y animaciones.
- **Particles.js**: Efectos de partículas en el fondo.

## Estructura del Proyecto

```
PORTFOLIO/
├── index.html          # Página de carga/loader
├── home.html           # Página principal
├── trayectoria.html    # Página de trayectoria profesional
├── proyectos.html      # Página de proyectos
├── contacto.html       # Página de contacto
├── loader.html         # Página adicional de loader
├── css/
│   └── styles.css      # Estilos CSS
├── js/
│   ├── loader.js       # Script para el loader
│   ├── particles-config.js  # Configuración de particles.js
│   ├── terminal.js     # Script para la terminal simulada
│   └── typing.js       # Animación de escritura
├── img/                # Imágenes (perfil, etc.)
└── cv/                 # Archivos del CV
```

## Cómo Ejecutar

1. Clona o descarga el repositorio.
2. Abre `index.html` en tu navegador web preferido.
3. El sitio se cargará comenzando por la pantalla de loader.

Como es un sitio estático, no requiere servidor ni instalación de dependencias. Simplemente abre los archivos HTML en un navegador.

## Navegación

- **🏠 Home**: Página principal con presentación.
- **👤 Trayectoria**: Experiencia profesional.
- **💼 Proyectos**: Portafolio de proyectos.
- **✉️ Contacto**: Información de contacto.
